# 8–12 Week Shadow-Mode Pilot Plan

Weeks 1–2: data mapping, consent/permission review, security controls, baseline incumbent metrics.
Weeks 3–6: shadow scoring only; compare incumbent vs Credit Sense without changing approvals.
Weeks 7–8: subgroup/error/calibration review, reason-code review, operational review-time measurement.
Weeks 9–12: limited controlled human-review workflow if governance approves.

Success/stop framework: pre-register thresholds for calibration error, approval/bad-rate trade-off, manual-review rate, latency, fairness diagnostics, data-quality failure, and complaint/reason-code issues. **Go/Modify/No-Go must be decided by lender model-risk/compliance governance, not this prototype.**
